Semi-Automatic Carton Sealer :

About Machine :

Semi-automatic carton sealing machine with three motors and side driving belt.

Carton size adjustment is manual ( suitable for sealing cartons of the same size ).

you can easily and quickly adjust the device according to the width and height of the box, and the same amount of tape is applied to each box.

1 Output speed 20 - 50 pcs/min
2 Carton size L×W×H (mm) (250-1000)×(150-500)×(200-500)
3 Voltage 220v - 50hz single phase
4 Power 360w
5 Machine weight 130 kg
6 Machine size 940 × 1750 × 1400 mm ( W×L×H )
7 Wrapping material PVC straps
8 Noise level of machine less than 70db
9 Wide tape 50 - 70 mm
